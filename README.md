# Desafio de Galeria de Imagens com Favoritos - Processo Seletivo Frontend Fusion


Este é um projeto de galeria de imagens desenvolvido com **React**, **Redux** e **Ant Design**. O projeto permite que os usuários visualizem imagens, adicionem imagens aos favoritos, removam imagens da lista de favoritos e exiba notificações ao realizar essas ações.  

![Minha Imagem do Google Drive](https://drive.google.com/uc?export=view&id=1kM3WTPnqjM1fTAV08uNwgfO6tgDKY1PQ)   
[Galeria de Imagens - Frontend Fusion](https://desafio-galeria-de-imagem-frontendfus.netlify.app/)  

## Funcionalidades

- Exibição de imagens de uma API externa (Picsum Photos).
- Adicionar imagens aos favoritos.
- Remover imagens dos favoritos.
- Exibir notificações ao adicionar ou remover imagens dos favoritos.
- Armazenamento dos favoritos no Redux.
- Exibição dos favoritos em uma seção separada.
- Detalhes da imagem como nome do Autor e Dimensões

  ![Descrição da Imagem](https://drive.google.com/uc?export=view&id=1K8gUg3m-zEO8LmM--ZZAmgzvzkVwDsxK)


## Tecnologias Utilizadas

- **React**: Biblioteca JavaScript para construção de interfaces de usuário.
- **Redux**: Biblioteca para gerenciamento do estado global da aplicação.
- **Ant Design**: Biblioteca de componentes React para design e interface do usuário.
- **Axios**: Cliente HTTP para buscar imagens da API externa.
- **React-Redux**: Conecta o Redux ao React para gerenciamento de estado.
